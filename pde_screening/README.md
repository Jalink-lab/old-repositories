# PDE_Screening

This contains the analysis code for the PDE screen. 

## A story about branches
Most users seem to push always to the master branch, even if they are still developing. This causes several conflicts and makes the master branch unstable. It is customary to branch-off when you develop something, and only when you are completely happy with it you create a pull-request to merge your branch (containing the updates) into the master branch. If this is accepted (and since we are all developers it can just be accepted by yourself), it can be merged.

## Even more text about branches
Everybody can make a branch, and only merge when happy about the change.

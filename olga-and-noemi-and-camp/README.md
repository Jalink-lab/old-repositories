# Olga and Noemi and cAMP

Project for learning to program in python and fiji
Also for learning to structure the code development process

Three main goals (from Olgas point of view)
1) Importing, processing and analysing all kinds of imaging data from different instruments in python and/or Fiji

2) Simulations of cAMP in the cell
Starting with simplified approach and tring to introduce more complexity as I improve in programming

3) Being able to program / modify adruino commands (eg. to operate the syringe pump for automatic stimulus injection; the shutter-opener for caged-compound release; etc)
